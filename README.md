This repo houses completed projects. The goal is to showcase projects that exhibit proficiencies in data science. 

The projects included in this repo are :

1. Churn Analysis:
Customer turnover is a concern for business across many industries. The ability to identify at risk clients before they leave is essential to maintain marketshare. Understanding customer behavior and migration habits the firm is able to craft programs to promote client retention. This analysis uses a sophisticated artificial neural network to accomplish this goal.

2. Fraud Detection:
In this project I used synthetic data to analyze transaction data to identify fraudulent transactions. The data for this analysis was obtained from Kaggle. To accomplish this goal, I completed a series of transformations. To complete the analysis, I built a pipeline and ran a logistic regression. In addition, I used the data to build an app to identify a fraudulent transaction.

3 X-Ray Analysis:
Innovation drives medical advancements. We're seeing more technical advancements happening in the medical field. These advancements are responsible for improvements in quality of life for millions of individuals. One of these advancements is the use of machine learning and AI in medical diagnosis. In this analysis I built a convolutional neural network (CNN) to identify the differences between heathy and diseased lungs.

4. Online Retailer Sales Analysis:
Retailers need a clear view of where revenue comes from and how it is likely to move. In this project I analyzed a 2019-2020 export of European product orders, cleaning messy headers and currency-formatted fields before exploring sales, cost, and country patterns. I then built regression models (linear, Huber, and XGBoost) to estimate net sales from order attributes. Order dates are irregular, so I resampled to monthly totals and compared a manual SARIMA specification with an automated ARIMA search. I also built a Streamlit app to explore the EDA, regressors, and forecasts.

5. Stock Analysis:
Constructing a book from a handful of names is as much about risk as it is about return. In this project I analyzed five large-cap technology stocks (AAPL, MSFT, GOOGL, NVDA, and TSLA) using daily prices from Yahoo Finance. I applied technical indicators (moving averages, Bollinger Bands, and MACD) and compared long-only weighting schemes, carrying an inverse-volatility allocation forward as the diversified book. A Monte Carlo simulation mapped the feasible set of portfolios and bootstrapped forward paths of that book, with the risk-free rate pulled from FRED. I also built a Streamlit app to compare the stocks side by side and review the Monte Carlo results.
